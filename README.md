Entry for the make.fun bounty [Describe Your Ex in One Word](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7).

The entry is a single word: **recalled**. The ex, summed up as a defective product the manufacturer took back.

## How it works

`main.ts` (Node 22, standard library only) validates the word against the bounty gate (1 to 111 characters, exactly one word, no surrounding whitespace) and writes it to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`, then reads it back to confirm the write.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
